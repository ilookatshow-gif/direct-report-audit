# direct-report-audit

Небольшой самостоятельный offline CLI для проверки выгрузки Яндекс Директа по площадкам. Python 3.9+, только стандартная библиотека; Harness, ключи, кабинет и сеть не нужны.

Суммирует показатели одной площадки, считает общий и построчный CPC/CPA, помечает кандидатов для **ручной проверки**. Не добавляет минус-площадки, не меняет кампании, не прогнозирует экономию. Нулевая конверсия сама по себе не доказывает неэффективность.

## Запуск и необязательная установка

Из папки модуля:

```sh
python3 direct_report_audit.py --json doctor
python3 direct_report_audit.py schema
python3 direct_report_audit.py --json audit examples/synthetic-placements.csv --max-cpa 1000
python3 -B -m unittest discover -s tests -v
```

Установка не обращается в сеть и не требует pip. Не перезаписывает существующую команду без `--replace`:

```sh
python3 install.py --prefix "$HOME/.local"
export PATH="$HOME/.local/bin:$PATH"
direct-report-audit --json doctor
direct-report-audit onboard --state-file "$HOME/.local/state/direct-report-audit/onboarding.json"
```

`onboard` — единственная команда, записывающая состояние; путь нужно выбрать явно. Она показывает автора один раз для этого marker-файла. `audit`, `doctor`, `schema` никогда не показывают рекламную вставку и не пишут файлы. Для Windows или запуска без установки используйте `python <абсолютный путь>/direct_report_audit.py ...`.

## Контракт входа

UTF-8, допустим BOM; CSV с запятой/`;` либо TSV. Первая содержательная строка — заголовок с **ровно пятью** полями (порядок произвольный):

```text
Placement,Impressions,Clicks,Cost,Conversions
```

- Числа неотрицательные. Показы/клики целые; дробные конверсии атрибуции сохраняются. До 18 цифр в одном числе.
- Десятичный разделитель — точка или запятая; разделитель тысяч — пробел/NBSP/узкий NBSP, группы по три цифры. `1 200,50` и `1200.50` допустимы; `1,234.56`, экспоненты, currency symbols, NaN/Infinity не допускаются.
- При comma CSV десятичную запятую и запятую в названии надо заключить в кавычки: `"example, placement",100,20,"1 200,50",0`.
- `Cost` **уже в денежных единицах**, не в микроденежных единицах raw API. Смешивать валюты, периоды, цели/модели атрибуции нельзя. `--currency` — только подпись, не конвертер: 1–12 ASCII букв/цифр с допустимыми `_.-`, например RUB/USD.
- Это нормализованный контракт, не парсер любых native-выгрузок/API Direct: переименуйте заголовки и удалите служебный preamble/футер/все строки итогов локально. Код отклоняет только известные метки `Total`, `Totals`, `Summary`, `Итого`, `Всего`, `Итого за период`, `Всего за период` (регистр не важен, завершающее `:`/`：` допустимо). Произвольные названия вроде «Итого по кампании» автоматически не распознаются: удалите их заранее, чтобы не удвоить суммы.
- До заголовка допустимы только пустые строки и `#`-комментарии. `# SYNTHETIC` явно маркирует учебные данные в выводе. Пример в `examples/` полностью вымышленный, не клиентский кейс.
- Площадка агрегируется по точному имени после удаления краевых пробелов; регистр и различные написания не объединяются. Повторные строки суммируются; строка-дубликат экспорта не распознаётся автоматически.
- Максимум 25 MB и 100 000 строк. Ошибочная строка прекращает весь анализ — частичные суммы не выдаются.

## Пороги и выход

```sh
direct-report-audit --json audit /local/private/placements.tsv \
  --min-clicks 30 --min-cost 1500 --max-cpa 2000 --min-conversions 2
```

По умолчанию `min-clicks=20`, `min-cost=1000`, `min-conversions=1`, проверка max-CPA выключена. Это демонстрационные настройки, не универсальные нормативы. Для объединённой площадки:

- `zero_conversion_spend`: конверсий 0, стоимость >0, достигнуты min-clicks и min-cost;
- `cpa_above_threshold`: достигнуты min-clicks/min-cost/min-conversions, точный CPA строго выше заданного max-CPA.

Сначала проверить задержку атрибуции, цели/трекер, период, выборку, тип конверсий и качество/оплаты из CRM. Один наблюдаемый отчёт — не причинный эксперимент.

JSON: `{ "ok": true, "command": "audit", "result": {...} }`. В `result` — `input`, `currency`, `thresholds`, `totals`, `placements`, `candidate_count`, `limitations`. Показы/клики — integers; cost/conversions — точные decimal strings; CPC/CPA — decimal strings, округлённые до 2 знаков, или `null` при нулевом знаменателе. Общий CPC/CPA вычисляется из общих сумм, не усреднением отношений. Сравнение порога использует неокруглённый CPA. Площадки сортируются по расходу вниз, затем имени.

Ошибка под `--json`: `{ "ok": false, "error": { "code": "invalid_input", "message": "..." } }`, exit 2; успех exit 0. Прогресс/реклама не загрязняют JSON. `--help` и `--version` — обычный текст.
