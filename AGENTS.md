# Module scope

This is a standalone offline file-analysis tool. No network, auth, account lookup, campaign mutation, automatic placement exclusions, or savings claims.

Read README.md/README.ru.md before changing the CSV contract. Preserve exact Decimal sums, integer Impressions/Clicks, fractional Conversions, zero-denominator nulls, and explicit synthetic labeling. Invalid input must fail without partial totals.

Run `python3 -B -m unittest discover -s tests -v`. Keep source exports/results private; use only the synthetic example in public demos. Do not access credentials or copy source/client data from Harness.

Author links belong in README and the explicitly requested one-time onboard command, not repeated audit output. GitHub publication, remote changes, real data upload and recurring automation require their own authorized task.
